# Student Print Farm help

This guide is the approved source for general student troubleshooting in the
UWA 3D Print Farm help chat. The chat explains how the portal works, but it
cannot inspect an account, a print file, a job, or a notification.

## Keep account details safe

Never paste a password, verification code, confirmation link, access token, or
other secret into the help chat. Print Farm staff and the help chat do not need
those values to answer a question.

## Create and verify a student account

Only students can create their own account from the public portal. Select
**Student**, choose **Create a student account**, and enter the requested name,
UWA student email, department, and a password of at least eight characters.
Self-service registration always creates a student account; a role cannot be
selected during registration.

After registration, enter the six-digit verification code sent to the student
email address. The code expires. If it does not arrive, check the junk or spam
folder, confirm that the address was typed correctly, and use **Resend code**
after the timer finishes. Use **Change email** to correct the address and
register again.

Email verification does not sign the student in. After successful verification,
return to Sign-in and use the registered email and password.

## Sign in

Students, printer farmers, and administrators use the same portal. Choose the
access card that matches the role already assigned to the account. Students
must choose **Student** and use their UWA student email address. Passwords are
case-sensitive.

If sign-in fails, check the email address, password, and selected access card
before trying again. For account recovery or a locked or disabled account,
contact the UWA Print Farm team.

## Prepare a file for upload

The portal accepts pre-sliced `.gcode` and `.bgcode` files generated by
PrusaSlicer. It does not slice an STL or other model file. The maximum upload
size is 50 MB.

Use a supported UWA printer profile and check the selected printer model,
material, and print settings in PrusaSlicer before exporting. A `.bgcode` file
requires server-side binary G-code support. If `.bgcode` conversion is
unavailable, export normal text `.gcode` from PrusaSlicer and try again.

## Upload and validate a file

Open **Upload file**, choose the sliced file, and wait for validation. The
portal checks the file format and integrity, required slicer metadata, printer
commands, safety limits, and compatibility with configured printers.

The file is not submitted to a queue merely by choosing it. A file that passes
validation shows its estimated duration, estimated filament use, indicative
cost, compatible printers, and matching materials. Select an available
compatible printer and material, then choose **Submit to print queue**.

### If validation fails

Read the validation message and correct the file in PrusaSlicer before
uploading it again. Common causes include:

- the file is empty, larger than 50 MB, corrupted, or has an unsupported
  extension;
- a `.gcode` file contains binary data, or a `.bgcode` file cannot be converted;
- required PrusaSlicer configuration or material metadata is missing;
- the printer model in the metadata conflicts with the executable G-code;
- the file uses an unsupported printer profile or exceeds a safety limit; or
- the file is incomplete and does not contain a safe end sequence.

Do not rename an STL or another file to `.gcode`; renaming does not create
valid G-code. Re-slice the original model with a supported PrusaSlicer profile.

### If no printer or material can be selected

Only printers compatible with the validated profile can be used. A compatible
printer may also be temporarily unavailable, offline, in maintenance, or in an
error state. The selected material must match the material recorded in the
file. If no matching printer or material is available, contact the UWA Print
Farm team rather than changing file metadata manually.

## Price estimate

The current indicative price is **$2.00 for the first hour** plus **$0.50 for
each additional hour**, calculated proportionally for partial additional
hours. For example, a 90-minute estimate is $2.25.

This is an estimate based on print duration, not a final University charge.
Rates and billing arrangements may change, and online payment is not currently
taken through this workflow.

## Submit and track a job

After a successful submission, the portal shows **Added to the queue** with
estimated start and completion times. Open **My jobs** to view active jobs and
print history. Students can view their own jobs; the help chat cannot look up a
job or its position.

Estimated times can change when earlier jobs take longer than expected, a
printer is paused or unavailable, or a farmer must resolve a printer problem.
Refresh or return to **My jobs** to see the latest information.

## How the queue works

Jobs for a printer are processed first come, first served using their submission
times. Each job is associated with a compatible selected printer, so there is
not one fixed position across every printer in the farm. A job waiting for one
printer does not reserve or block a different printer.

Submitting the same file again creates another job; do not resubmit merely
because a queued job has not started. Check **My jobs** first. Contact the UWA
Print Farm team if a job appears stuck or its estimates stop updating.

## Job updates and notifications

A successful submission is confirmed immediately on screen. In-app
notifications then report important job events, including when a print starts,
is paused, resumes, completes, or fails. Use the bell in the portal header or
open **Notifications**. New notifications appear automatically and can be
marked as read.

If a printer reports an error or stops unexpectedly, the job may be marked as
failed and the notification may include a short reason. Do not attempt to
operate or repair a printer. Contact the UWA Print Farm team if the message
does not explain what to do.

## Completion and collection

**Completed** means that printing has finished; it does not by itself confirm
that the item is safe and ready to collect. A printer farmer may need to let the
bed cool, remove the print, and complete the collection process. Follow any
ready-for-collection instruction shown by the portal or contact the UWA Print
Farm team before collecting the item.

## Help outside this guide

Contact the UWA Print Farm team when:

- an account needs recovery or is locked or disabled;
- repeated uploads fail after the file has been re-sliced correctly;
- no compatible printer or matching material is available;
- a queued job appears stuck or a printer reports a problem;
- collection instructions are unclear; or
- the question is not answered by this guide.

The help chat provides general troubleshooting only. It cannot change an
account, file, job, queue, printer, price, notification, or collection status.
